## Why Java?
For the past near month I have been absent from the blog. Why? While studying and preparing for my next semester as a college student at CSU, my advisor mentioned that Java is a commonly used language at CSU. Coming from Colorado Mesa University, I had no experience with Java, as their ciriculum was mainly C++ and Python. Additionally, Java is a somewhat popular language, and I wanted to learn it, as learning a few new langauages cant hurt. 

## Installing Java
Insalling Java seemed strange to me, as it was not included in VSCode or a base microsoft product. Instead I had to install it from an extension. What I found even more strange was the many different types of Java, and the different companies behind them. Eventually I settled on installing the JDK version, due to its popularity.

## First Impressions
When learning the basic syntax of Java I first noticed it was very different to python, which is expected as python is designed to be read easily. However the sheer amount of syntax and structure needed to perform a simple "Hello World" shocked me. Even more suprising was the fact that the interpreter wouldnt allow the code to be ran until the file name matched the class name. I understand that mathcing the main class name and the file name is best practice, however not allowing the program to run seems a bit strange to me.

## Future Goals
For the next few weeks I hope to learn more Java and be more proficient with it. Navigating its syntax seems daughting right now, but I am confident I will be able to use to.
